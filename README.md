# imvault-mac

Native macOS GUI for [imvault](https://github.com/reznto/imvault) — an iMessage archiver and viewer.

This repo is being scaffolded. The architecture, phase plan, and design constraints live in `docs/mac-app-plan.md` of the [`reznto/imvault`](https://github.com/reznto/imvault) repo (the source of truth).
